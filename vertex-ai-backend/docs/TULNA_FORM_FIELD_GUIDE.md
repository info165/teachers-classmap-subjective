## Product description (use this, edited for accuracy)
> ClassMap helps teachers find each student's learning gaps quickly, inside the class and
> without extra setup. A teacher can run a base test in class, or push a test to students'
> phones through the student app. After the base test, each student is offered personalised
> practice: a retest on the topics they are weakest in. Teachers see class-level strengths and
> weaknesses per topic, and per-student results for pushed tests. Teachers can also set
> subjective (short and long answer) tests. ClassMap's personalised adaptive learning (PAL)
> targets each student's gaps; that is the core of the product.

Do not claim (until verified or changed):
- "Unlimited objective tests for free": **Verify.** Higher practice levels are paid in the app.
- "Subjective answers checked by AI for handwritten work": **Verify.** A grading pipeline exists;
  confirm it is live for students before stating it.
- "70,000+ questions in English and Hindi": use "78,765 published questions in English across
  classes 6–10, maths, science, English and social studies." Hindi is in progress (one chapter
  live), so say "Hindi in progress", not "available".
- "Every question has rubrics and detailed explanations": only subjective questions carry rubrics.
  Most objective questions have explanations, but some explanations have wrong option letters.
  Say "most objective questions have explanations; subjective questions have marking rubrics."
- "True/false, assertion-reason, fill-in-the-blank supported": **Verify** before listing them.
  The app supports them, but no live test of these types has been run. Case-based questions are
  supported as passage plus parts.
